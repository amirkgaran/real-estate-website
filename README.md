# myinvest.ca

Investment and real estate website for Amir Geran, Broker at International Realty Firm.

## Public pages

- Home
- About
- Contact
- Residential
- Multi Residential
- Commercial
- Financial Market

## Listing management

The site includes a private authenticated admin dashboard at:

`/admin.html`

Listings and photos are stored in Supabase. Published listings automatically appear on the appropriate category page.

See `SUPABASE_SETUP.md` for installation instructions.

## Hosting

The public website is hosted with GitHub Pages.

Keep the `CNAME` file unchanged so the custom domain continues to work.
