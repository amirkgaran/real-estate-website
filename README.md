## Hosting

This website is hosted using GitHub Pages and published from the `main` branch.

The `CNAME` file should not be deleted or changed unless the website domain changes.

## Updating the Website

After editing or uploading website files:

1. Commit the changes to the `main` branch.
2. GitHub Pages will automatically rebuild the website.
3. Allow a few minutes for changes to appear at www.myinvest.ca.
