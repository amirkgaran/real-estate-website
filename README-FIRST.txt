MYINVEST - CONTACT FORM + EDITABLE ABOUT UPDATE

1) SUPABASE (run once)
Open Supabase -> SQL Editor -> New query.
Paste and run:
  supabase-site-content-migration.sql

2) GITHUB
Open the real-estate-website repository on the main branch.
Choose Add file -> Upload files.
Upload these files to the ROOT of the repository, replacing existing files when prompted:
  index.html
  about.html
  contact.html
  admin.html
  admin.js
  site-content.js
  site-content.css
  contact-form.js
  thank-you.html

Commit the changes.

3) FORM ACTIVATION
After GitHub Pages deploys, open:
  https://www.myinvest.ca/contact.html
Submit the form once yourself.
FormSubmit may send a one-time activation email to amirkgaran@gmail.com.
Approve it if requested. Future submissions will then be forwarded there.

4) EDIT ABOUT FROM ADMIN
Open:
  https://www.myinvest.ca/admin.html
Sign in.
Use Website Content -> About page.
Change the heading and description and click Save About page.
No GitHub edit is needed for future About changes.
